# Hopping Hiyoko

レトロゲームエンジン
[Pyxel](https://kitao.dev/pyxel/)
を用いて制作したアクションゲームです。

ひよこを操作して、より高い場所を目指して進みます。ひよこが敵に当たるまでに到達した高さがスコアとなります。

## 操作方法

### キーボード

- 左へ移動：`Left` / `A`
- 右へ移動：`Right` / `D`
- ジャンプ：`Space` / `Enter` / `Z`

### スマートフォン・タブレット
スマートフォンやタブレットでも遊ぶことができますが、キーボードと比較すると操作がしづらくなります。

- 左へ移動：`Left`
- 右へ移動：`Right`
- ジャンプ：右側の任意のボタン
