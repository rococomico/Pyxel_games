# Pyxel_games

レトロゲームエンジン
[Pyxel](https://github.com/kitao/pyxel/blob/main/docs/README.ja.md)
を用いてゲームを作成しました.

## Hopping Hiyoko

ひよこを操作してより高い場所を目指すアクションゲームです.
ひよこが敵に当たるまでに到達した高さがスコアとなります.

### 操作方法
キーボードを用いて操作します. 操作方法は以下の通りです.

- 左へ移動: `Left` / `A`
- 右へ移動: `Right` / `D`
- ジャンプ: `Space` / `Enter` / `Z`

また, スマートフォン, タブレットでも遊ぶことができます. ただし, キーボードと比較して操作がしづらくなります.

- 左へ移動: `Left`
- 右へ移動: `Right`
- ジャンプ: 右側の任意のボタン
